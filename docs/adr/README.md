# Architecture Decision Records

Aquí se registran las decisiones de arquitectura importantes: qué se decidió, por qué y qué consecuencias tiene. Así, dentro de seis meses nadie tendrá que adivinar por qué algo se hizo así.

## Cuándo escribir un ADR

- Elegir una tecnología, librería o patrón con alternativas razonables.
- Cambiar algo que afecta a varios módulos.
- Cualquier decisión que alguien pueda querer revertir sin conocer el motivo.

## Formato

Copia [0000-template.md](0000-template.md) como `NNNN-titulo-corto.md`. Los ADR aceptados no se editan: si una decisión cambia, se escribe un ADR nuevo que sustituye al anterior.
